# art

The pieces as they arrive, cut out and squared. The site does not load
anything in here — it is the source the NFT images get built from.

## beings

One file per being. Black has been keyed out, so each one is transparent
where the background was and can be laid over a field, a light and a frame
without a black box round it. Soft edges — the Epic's starfield haze, for
instance — survive as partial transparency and blend properly.

| File | Native size | Notes |
|------|-------------|-------|
| `uncommon-grey.png` | 89 × 89 | a true sprite: chunky blocks, about 2,800 of them |
| `epic-crowned.png` | 1244 × 1244 | dithered line art, no block grid — roughly 5× denser |

**The two are not drawn at the same pixel size**, and that is still an open
decision. Until it is settled, each piece is kept at whatever density it
arrived at rather than being forced onto a shared grid, because squashing
down is reversible and inventing detail is not.
